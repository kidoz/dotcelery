# Tutorials

[Documentation](../README.md) / Tutorials

Follow these lessons in order if you are new to DotCelery. Each gives you a small
working result and observations to check along the way.

1. [Run your first task](first-task.md): create a client and worker, submit an
   addition task, and read its result without external services.
2. [Explore the dashboard](dashboard-tour.md): run the demo, find a task, inspect
   its details, and read a versioned API response.

If you already know the basics and need to finish a particular job, choose a
[how-to guide](../how-to/README.md).
